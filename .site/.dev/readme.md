# Site

Project within a project, eh?

Yeah, the *Assort* site is pretty massive, and I shudder to imagine anyone trying to navigate this for the first time. In all honesty tho, it’s really not that bad, and I’m sure professional projects are even larger scale.


<br>


## Directory

Here’s an overview of where everything is!

### Folders

| folder | subfolder | notes |
| :----- | :-------- | :---- |
| `data/` | | JSON files |
| `modules/` | `stores/` | Svelte stores, particularly those persisted to `localStorage` |
|           | `types/` | type (`class`) definitions |
|           | `utils/` | utility functions |
| `palettes/` | | colour palettes data, auto-generated by *Vividity* |
| `parts/` | `base/` | templates for *Squarkdown* |
|         | `core/` | core site-wide UI |
|         | `ext/` | more specialised UI components |
|         | `misc/` | rarely used one-off UI components |
|         | `page/` | components for articles |
|         | `popups/` | popup windows |
|         | `views/` | blocks |
| `routes/` | `(article)/(rendered)` | articles exported from *Assort*, auto-generated by *Squarkdown* |
|           | `(article)/(static)` | special pages hand-written in Svelte |
|           | `(home)/` | the home page |
| `styles/` | `mixins/` | global mixins, prepended to all SCSS `<style>` tags by *Squarkdown* |
|           | `pages/` | different page styles, used by *Squarkdown* |

### Files

| file | path | notes |
| :--- | :--- | :---- |
| `scss-config.js` | `./scss-config.js` | SCSS configurations, auto-generated by *Squarkdown* |
| `site.ts` | `./src/site.ts` | exports the global `Site` object for accessing all site data |
| `essence.scss` | `./src/styles/essence.scss` | global SCSS styles applied to all pages |
