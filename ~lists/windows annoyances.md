I can’t imagine using anything other than Windows, but oh my days does it suck.


- In Windows 11, using `ctrl`+`win`+`left`/`right` to switch virtual desktops is painfully delayed.
  - Update: this *might* have been fixed?
- This is an old one, but never in my entire life of using Windows has the Start search menu been able to find anything except installed apps.
  - And now it won’t even search for files unless you specifically switch to “Documents”. Which just redirects you to File Explorer’s search, so *what was even the point of using Start’s search*.
- Speaking of which, File Explorer’s search is slow, inaccurate and all-round useless.
- Pressing `win`+`space` to switch keyboard languages only shows the menu after a solid ~0.5s. If you let go before then, it still switches input language, it just won’t give you any visual feedback. **Any at all.**
